# XML Configuration & Output Schema Documentation

## 1. Policy on XML Files

In accordance with repository engineering discipline:
- **No arbitrary or decorative XML files** are created in this repository.
- XML formats are used **strictly where a genuine tool consumer requires them**.
- The sole legitimate XML artifact in the SJCCC developer infrastructure is the **standard JUnit XML test report** (`reports/junit.xml`), generated by the automated test suite during CI and verification workflows.

---

## 2. JUnit XML Test Report Specification

| Attribute | Details |
| :--- | :--- |
| **Artifact Path** | `reports/junit.xml` |
| **Generating Tool** | Vitest (`vitest run --reporter=junit --outputFile=reports/junit.xml` or `npm run test:ci`) |
| **Consumer** | Continuous Integration engines (GitHub Actions, GitLab CI, Jenkins), test dashboard visualizers, and IDE test explorers. |
| **Schema Standard** | JUnit Ant XML Schema (`<testsuites>`, `<testsuite>`, `<testcase>`, `<failure>`, `<error>`). |
| **Lifecycle** | Generated during test execution; output directory `reports/` is tracked via `.gitkeep` with report files excluded in `.gitignore` to prevent repository bloat. |

### Sample Valid Schema:

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<testsuites name="vitest tests" tests="15" failures="0" errors="0" time="0.35">
    <testsuite name="tests/audit/html-integrity.test.ts" tests="4" failures="0" errors="0" skipped="0" time="0.32">
        <testcase classname="tests/audit/html-integrity.test.ts" name="HTML Document &amp; Accessibility Integrity Audit &gt; should validate Homepage (index.html) structure with 0 errors" time="0.18">
        </testcase>
        <testcase classname="tests/audit/html-integrity.test.ts" name="HTML Document &amp; Accessibility Integrity Audit &gt; should validate Prospectus (prospectus.html) structure with 0 errors" time="0.03">
        </testcase>
    </testsuite>
</testsuites>
```
